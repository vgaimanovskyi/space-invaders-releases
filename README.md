# space-invaders-releases

Prebuilt Windows and macOS zip downloads for **Space Invaders**, published from the private source repository. No source code lives here.

## Download latest release

- [Windows](https://github.com/vgaimanovskyi/space-invaders-releases/releases/latest/download/Space_Invaders_Game_win.zip)
- [macOS](https://github.com/vgaimanovskyi/space-invaders-releases/releases/latest/download/Space_Invaders_Game_macOS.zip)

These links always point to the current latest release, so there is no need to open the Releases page to download.
